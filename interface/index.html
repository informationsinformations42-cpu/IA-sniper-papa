CONNEXIONS AUTORISÉES

Comptes e-mail

OAUTH · JAMAIS DE MOT DE PASSE

Recherche un fournisseur, puis connecte-toi sur sa page officielle. L’application ne reçoit pas ton mot de passe; les jetons sont chiffrés par le coffre du système. « Déconnecter » les efface de cet appareil. Pour révoquer aussi l’autorisation côté fournisseur, retire l’application dans les paramètres de sécurité Google ou Microsoft. Les envois manuels demandent une confirmation système; les réponses automatiques restent désactivées tant que tu ne les actives pas pour une liste d’expéditeurs approuvés.

CONFIGURATION INITIALE

Identifiant OAuth public

Google : active Gmail API, crée un client OAuth « Application de bureau » et ajoute ton compte comme utilisateur de test si Google le demande. Microsoft : crée une application publique pour bureau et active les permissions déléguées de courrier. Colle seulement l’identifiant public; ne colle jamais ton mot de passe ni un secret client. La connexion demandera les permissions de lecture, brouillons et envoi.
